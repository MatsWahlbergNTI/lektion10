Lektion 15 - Responsiv Design

Att en hemsida är responsiv betyder att den anpassar sig för olika skärmstorlekar.

Så länge man inte lägger in CSS är i princip hemsidor responsiva

Resposiva hemsidor kan göras med bland annat procent, flex, grid och media queries.

Dagen uppgift är att kommentera koden i den här hemsidan

  • CSS
  • Flex
  • Grid
  • Media queries
  • JavaScript
